# Как работает настоящий режим

Сервер на Supabase (проект `zvezdny-pak`) уже развёрнут. Приложение Twitch **не нужно**: всё работает через чат канала.

## Как это устроено
- **Вход зрителя.** Зритель вводит на сайте свой ник и получает код. Он пишет в чате канала `!пак 1234`, и сайт его узнаёт. Вход сохраняется на 60 дней.
- **Пакетики.** На Twitch есть награда **«Звёздный пак»** за баллы канала, с полем для текста. Каждая покупка даёт зрителю пакетик на сайте.
- **Кто слушает чат.** Это **мост**: оверлей `overlay.html` с ключом стримера. Он открыт в OBS и анонимно читает чат, как гость. Коды входа и покупки награды он пересылает на сервер.
- **Розыгрыш и коллекции** живут на сервере. Подкрутить шансы или дописать себе пакетики из браузера нельзя.

> Мост работает, пока открыт оверлей: в OBS во время стрима или просто во вкладке браузера.

## Настройка (один раз)
Панель Supabase не нужна.
1. **Канал.** Логин канала хранится в базе (`settings.channel`). Его вписывает разработчик, сайт и оверлей подхватывают его сами.
2. **Ключ стримера.** Когда открыто окно настройки, на вкладке «Стример» появляется блок «Придумай ключ стримера». Ключ — это пароль от панели и моста, от 16 символов. Сервер хранит только его хеш. Задать ключ можно один раз.
3. **Награда на Twitch:** Панель управления автора → Награды зрителей → Баллы канала → Управление наградами → «Добавить награду».
   - Название: **Звёздный пак**, цена — какая хочешь.
   - Включи **«Попросить зрителя ввести текст»**: без этого покупка не появится в чате.
4. **OBS:** в панели нажми «Скопировать ссылку» (ссылка для OBS со встроенным мостом). Источник → Браузер → вставь ссылку, размер 1920×1080.
5. **Привязка награды:** при запущенном оверлее купи свою награду сам и напиши в поле **привязать**. В панели появится «Награда привязана».

## Параметры оверлея
- `?min=rare` — показывать на стриме только редкие и выше;
- `?sound=0` — без звука;
- `?status=1` — значок состояния моста в углу (удобно, если оверлей открыт во вкладке);
- `?test=1` — пробная плашка.

## Что где лежит
| Файл | Что делает |
|---|---|
| `supabase/migrations/…_init.sql` | таблицы, доступы, розыгрыш `open_pack`, крафт, начисление пакетиков |
| `supabase/migrations/…_chat_login.sql` | вход через чат: коды и сессии |
| `supabase/functions/api` | API сайта: вход, профиль, открыть пак, крафт, панель стримера |
| `supabase/functions/bridge` | приём событий из чата от оверлея (только с ключом стримера) |
| `supabase/functions/eventsub` | на будущее: приём наград через приложение Twitch, если оно появится |
| `config.js` | публичные настройки сайта |
| `overlay.html` | оверлей для OBS и мост чата |

## Безопасность
- В браузер зрителя попадает только публичный ключ Supabase: им можно читать карточки, настройки и ленту выпадений.
- Профили, пакетики и коллекции меняет только сервер.
- Сессии хранятся в базе в виде хеша.
- Ключ стримера хранится на сервере только как хеш; сам ключ есть в ссылке оверлея в OBS и в браузере стримера. Не показывай ссылку оверлея на стриме и никому её не отправляй.

## Если появится приложение Twitch
Впиши его Client ID в `config.js` → `twitchClientId`, задай секреты `TWITCH_CLIENT_ID`, `TWITCH_CLIENT_SECRET` и `EVENTSUB_SECRET`. Тогда вход пойдёт через Twitch, а награду можно будет создать кнопкой в панели.
